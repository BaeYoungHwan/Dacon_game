## 1. 게임 개요

**떡상러쉬**는 한국 주식 시장을 배경으로, 50라운드 동안 **정보의 비대칭**을 활용해 자산을 불리는 웹 기반 주식 시뮬레이션 미니게임입니다.

플레이어는 1천만 원으로 시장에 진입합니다. 종목과 차트는 보이지만 — 진짜 중요한 정보는 숨겨져 있습니다. **정보상(情報商)** 에서 매 라운드 국제·기업 뉴스를 무료로 확인하고, 추천 종목을 유료로 구매할 수 있습니다. **기술상(技術商)** 에게 돈을 내면 아직 공개되지 않은 종목에 남들보다 먼저 진입할 수 있습니다. 어디에 투자할지 — 매 라운드 플레이어의 판단이 결과를 바꿉니다.

| 항목 | 내용 |
|------|------|
| 장르 | 전략 시뮬레이션 / 경제 미니게임 |
| 플레이타임 | 첫 플레이 15~20분, 숙련 후 10~15분 |
| 플랫폼 | 브라우저 (PC + 모바일) |
| 별도 설치 | 없음 — URL 접속 즉시 플레이 |
| 회원가입 | 불필요 — 닉네임만 입력 |

---

## 2. 핵심 차별화: 정보 비대칭 메커니즘

일반 주식 게임과 달리, **떡상러쉬는 정보 구매를 핵심 전략 자원으로 설계**했습니다.

    정보 비대칭 구조
    ─────────────────────────────────────────────────
    모든 플레이어가 볼 수 있는 것
      ✓ 공개 10개 종목의 현재 주가 + 캔들스틱 차트
      ✓ KOSPI 지수 흐름
      ✓ 전 라운드 대비 등락률
      ✓ 국제 뉴스 / 기업 뉴스 (매 라운드 자동 공개)

    돈을 내야만 알 수 있는 것
      💰 정보상 → 추천 종목 (이번 주 주목 종목 힌트)
      💰 기술상 → 차트 지표 (MA·볼린저·MACD·OBV, 영구)
      💰 기술상 → 비공개 10개 종목 접근권

    트레이드오프: 추천 종목 구매 비용 = 투자 원금 감소
    ─────────────────────────────────────────────────

이 구조는 실제 주식 시장의 본질(기관·개인 간 정보 격차)을 게임 메커니즘으로 번역한 것입니다.
"추천 종목 정보를 살 것인가, 그 돈으로 직접 투자할 것인가" — 매 라운드의 선택이 플레이어를 몰입하게 합니다.

## 3. 핵심 규칙

### 기본 구조

| 항목 | 내용 |
|------|------|
| 초기 자본 | 10,000,000원 (1천만 원) |
| 총 라운드 | 50라운드 (각 라운드 = 실제 1주(週) 거래 단위) |
| 데이터 기반 | 코스피 실제 주봉 2025-05-29 ~ 2026-05-07 (50주, 매주 목요일 기준) |
| 승리 조건 | 코스피 지수 대비 초과 수익률로 등급 결정 |

### 등급 체계

코스피 기준선과 내 수익률의 차이(초과 수익률 %p)로 등급을 부여합니다.

| 등급 | 코스피 대비 초과 수익률 | 의미 |
|------|----------------------|------|
| 개미 | -10%p 이하 | 시장에 졌다 |
| 슈퍼개미 | -10%p ~ 0%p | 시장 추종 |
| 큰손 | 0%p ~ +50%p | 시장을 이겼다 |
| 작전세력 | +50%p ~ +200%p | 시장을 압도 |
| 전설의 동학개미 | +200%p 초과 | 레전드 |

### 종목 시스템

- 총 20개 종목 (코스피 대형주 20개, 한국 주식 커뮤니티 밈 감성으로 래핑)
- 게임 시작 시 **랜덤 10개 → 시장 공개**, 나머지 10개는 기술상에서만 접근 가능
- 매 게임마다 다른 10개 조합 → 같은 전략이 통하지 않음

### 정보 구매 시스템

| 구매처 | 제공 정보 | 비용 | 지속 기간 |
|--------|-----------|------|-----------|
| 정보상 | 국제 뉴스 (전 섹터 영향) | **무료 (자동 공개)** | 해당 라운드 |
| 정보상 | 기업 뉴스 (개별 종목 방향 힌트) | **무료 (자동 공개)** | 해당 라운드 |
| 정보상 | 추천 종목 (이번 주 주목 종목) | 라운드마다 변동 | 해당 라운드 |
| 기술상 | 차트 지표 4종 (MA·볼린저·MACD·OBV) | 1회 구매 | 게임 끝까지 |
| 기술상 | 비공개 종목 공개 + 매수 기회 | 라운드마다 변동 | 해당 라운드 |

### 가격 변동 알고리즘

- 주가 변동 = **실제 코스피 상장 종목 20개의 주봉 등락률 데이터를 라운드 순서대로 재생**
- 모든 데이터는 사전 수집 후 JSON 하드코딩 → 외부 API 불필요, 심사자 별도 키 없이 플레이 가능
- 정보상 뉴스 = 다음 주 실제 가격 방향을 암시하는 힌트 (정확한 수치는 비공개)

## 4. 플레이 방식

### 전체 게임 루프

    1. URL 접속 → 닉네임 입력 → 새 게임 시작
          ↓
    2. [메인 화면] 잔고·보유종목·KOSPI 확인
          ↓
       +------------------------------------------+
       |  [거래소] 종목 분석 + 매수/매도          |  <- 매 라운드 자유롭게 선택
       |  [정보상] 뉴스·지표 구매                |
       |  [기술상] 비공개 종목 유료 오픈         |
       +------------------------------------------+
          ↓
    3. [다음 주 ▶] 버튼 → 주가 변동 + 뉴스 발생
          ↓
    4. 2~3 50회 반복
          ↓
    5. [결과 화면] 최종 등급 확인 → 랭킹 등록

### 한 라운드의 흐름 (12라운드 예시)

| 단계 | 플레이어 행동 | 화면 |
|------|-------------|------|
| 1 | 잔고(8,432,000원)와 보유 종목 등락률 확인 | 메인 화면 |
| 2 | 정보상에서 뉴스 확인 (무료 자동 공개) + 추천 종목 구매 고민 | 정보상 모달 |
| 3 | 거래소 방문 → 뉴스 힌트 기반 반도체 종목 매수 | 마켓 화면 |
| 4 | [다음 주 ▶] 클릭 → 반도체 종목 +4.3% 상승 | 메인 화면 업데이트 |
| 5 | 수익 확인 후 다음 라운드 전략 재수립 | 메인 화면 |

### 10분 안에 경험하는 핵심 재미

10분 = 약 15~20라운드. 이 구간에서 게임의 핵심 재미가 모두 등장합니다.

| 라운드 구간 | 경험 내용 |
|-----------|-----------|
| 1~5라운드 | 무료 뉴스를 참고해도 불확실한 시장 → 추천 종목 구매 고민 시작 |
| 5~10라운드 | 첫 추천 종목 구매 → 힌트가 맞았을 때의 쾌감 |
| 10~15라운드 | 기술상 등장 (10라운드부터) → 비공개 종목 투자 기회 |
| 15~20라운드 | 전략 분기 선명: 정보 투자형 vs. 종목 집중형 |

## 5. 주요 재미 요소

### 정보 비대칭의 긴장감

매 라운드 뉴스는 공개되지만 "추천 종목을 살 것인가, 그 돈으로 직접 투자할 것인가" — 라는 판단이 긴장감을 만듭니다.
추천 종목을 샀는데 맞으면 쾌감, 틀리면 분노 → 다시 도전 욕구를 자극합니다.

### 한국 주식 밈 감성

종목명·뉴스 헤드라인·등급 멘트에 한국 주식 커뮤니티의 공감대를 녹였습니다.

- 뉴스 예시: *"동학개미 집결, 코스피 지지선 사수"* / *"외국인 매도 폭탄… 개미들 패닉셀"*
- 등급 예시: *"당신은 전설의 동학개미가 되었습니다"* / *"개미는 오늘도 털렸다"*

### 랭킹 경쟁으로 반복 플레이 유도

50라운드 완료 후 전체 순위에 닉네임과 수익률을 등록합니다.
"1등과의 차이가 얼마지?" 라는 순간이 재도전을 유발합니다.

### 매 게임 다른 경험

- 랜덤 공개 종목 조합 → 같은 전략이 통하지 않음
- 추천 종목 구매 타이밍과 금액에 따라 결과가 완전히 달라짐

## 6. 차별화 포인트

| 기존 주식 게임의 문제 | 떡상러쉬의 해결 |
|----------------------|----------------|
| 복잡한 회원가입 필수 | 닉네임만 입력, 즉시 플레이 |
| 30분~1시간 플레이타임 | 핵심 재미 10분 내 체험, 50라운드 완결 구조 |
| 단순 주가 예측 반복 | 정보 구매 vs. 종목 투자 트레이드오프가 핵심 전략 |
| 어렵고 딱딱한 UI | 한국 주식 밈 감성 + NPC 캐릭터로 친근함 |
| 실시간 데이터 의존 (접속 오류 위험) | 사전 수집 실제 데이터 → 외부 API 없이 안정적 동작 |
| 매번 똑같은 결과 | 랜덤 종목 조합으로 매 게임 다른 경험 |

## 8. 기술 스택

| 역할 | 기술 | 선택 이유 |
|------|------|-----------|
| 프론트엔드 | React 18 + Vite | 빠른 빌드, 컴포넌트 재사용 |
| 스타일링 | Tailwind CSS | 반응형 구현 속도 |
| 상태 관리 | Zustand + localStorage persist | 새로고침 복구, 이어하기 기능 |
| 랭킹 백엔드 | Supabase | 서버 없이 실시간 랭킹 DB |
| 배포 | Vercel | GitHub 자동 배포 |
| 개발 방식 | Claude Code (바이브 코딩) | 기획~배포 전 과정 AI 페어 프로그래밍 |

주가 데이터: 실제 코스피 종목 20개 + 지수 주봉 JSON 하드코딩 (50주) — 외부 API 의존 없음, 심사자 별도 키 불필요
