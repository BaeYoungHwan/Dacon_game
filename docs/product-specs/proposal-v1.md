## 1. 게임 개요

**떡상러쉬**는 한국 주식 시장을 배경으로, 50라운드 동안 정보의 비대칭을 활용해 자산을 불리는 웹 기반 주식 시뮬레이션 미니게임입니다.

플레이어는 제한된 현금으로 시장에 진입하고, 뉴스 이벤트를 읽으며 주가 흐름을 예측합니다. 단, 모든 정보는 공개되지 않습니다. **정보상(情報商)** 에게 돈을 지불하면 숨겨진 종목 정보와 국제 뉴스를 구매할 수 있고, **기술상(技術商)** 에게 돈을 지불하면 시장에 공개되지 않은 비밀 종목에 투자할 기회를 얻습니다. 정보에 투자할지, 종목에 투자할지 — 매 라운드 플레이어의 판단이 결과를 바꿉니다.

| 항목 | 내용 |
|------|------|
| 장르 | 전략 시뮬레이션 / 경제 미니게임 |
| 플레이타임 | 평균 15~20분 |
| 플랫폼 | 브라우저 (PC + 모바일) |
| 별도 설치 | 없음 — URL 접속 즉시 플레이 |
| 회원가입 | 불필요 — 닉네임만 입력 |

## 2. 핵심 규칙

### 기본 구조
- **초기 자본**: 10,000,000원 (1천만 원)
- **총 라운드**: 50라운드 (각 라운드 = 1거래일)
- **승리 조건**: 시뮬레이션 코스피 대비 초과 수익률로 등급 결정

### 등급 체계

> 시뮬레이션 코스피 = 게임 내 공개 10종목 평균 등락률 (외부 API 불필요)
> 내 수익률 − 코스피 수익률 = 초과 수익률(%p) 기준으로 등급 부여

| 등급 | 달성 조건 (코스피 대비 초과 수익률) | 의미 |
|------|-----------------------------------|----|
| 개미 | −10%p 이하 | 시장에 졌다 |
| 슈퍼개미 | −10%p ~ 0%p | 시장 추종 |
| 큰손 | 0%p ~ +50%p | 시장을 이겼다 |
| 작전세력 | +50%p ~ +200%p | 시장을 압도 |
| 전설의 동학개미 | +200%p 초과 | 레전드 |

### 종목 시스템
- 총 20개 종목 (한국 실제 종목·ETF 기반, 밈 이름으로 래핑)
- 게임 시작 시 **랜덤 10개 선택 → 시장에 공개**
- 나머지 10개는 기술상에서 유료로만 확인 가능

### 정보 비대칭 시스템
| 구매처 | 제공 정보 | 비용 |
|--------|-----------|------|
| 정보상 | 국제 뉴스, 기업 호재·악재 뉴스, 추천 종목 | 라운드마다 변동 |
| 기술상 | 공개되지 않은 종목 중 일부 공개 + 투자 가능 | 라운드마다 변동 |

> 정보를 사지 않으면 뉴스 없이 맨눈으로 버텨야 합니다. 정보에 쓴 돈은 투자 원금이 줄어드는 트레이드오프입니다.

### 가격 변동 알고리즘
- 매 라운드 종료 시 뉴스 이벤트가 발생하며 해당 섹터 종목 가격 변동
- 정보상에서 뉴스를 구매한 플레이어는 **다음 라운드 가격 방향**을 미리 예측 가능
- 기본 랜덤 변동폭 ±5%, 뉴스 이벤트 발생 시 ±10~30%

## 3. 플레이 방식

```
[시작] 닉네임 입력 → 새 게임 / 이어하기
   ↓
[메인] 현재 잔고·보유종목 현황 확인 → 어디로 갈지 선택
   ↓
┌──────────────────────────────────────┐
│  [거래소] 종목 분석 → 매수 / 매도   │
│  [정보상] 뉴스·추천종목 구매        │
│  [기술상] 비공개 종목 유료 오픈     │
└──────────────────────────────────────┘
   ↓
[라운드 종료] 수익/손실 요약 → 다음 라운드
   ↓ (50라운드 반복)
[결과] 최종 등급 확인 → 랭킹 등록
```

### 한 라운드의 흐름
1. 메인 화면에서 현재 잔고와 보유 종목 등락률 확인
2. 거래소·정보상·기술상 중 원하는 곳을 자유롭게 방문
3. 거래소에서 매수/매도 실행
4. "다음 날로 진행" 버튼 클릭 → 뉴스 발생 + 주가 변동
5. 라운드 결과 모달에서 손익 확인

## 4. 주요 재미 요소

### 정보 비대칭의 긴장감
공개된 정보만으로는 항상 부족합니다. "이번엔 정보상을 믿을까? 아니면 내 촉을 믿을까?" 라는 판단이 매 라운드 긴장감을 만듭니다.

### 한국 주식 밈 감성
종목명·뉴스 헤드라인·결과 멘트에 한국 주식 커뮤니티 밈을 녹여 공감대를 형성합니다.
- 예시 뉴스: *"동학개미 집결, 코스피 지지선 사수"*, *"외국인 매도 폭탄… 개미들 패닉셀"*
- 예시 결과 멘트: *"당신은 전설의 동학개미가 되었습니다"*

### 랭킹 경쟁
50라운드 한 판 플레이 후 전체 순위에 이름을 남깁니다. "다시 도전" 버튼 한 번으로 반복 플레이를 유도합니다.

### 매 게임 다른 경험
랜덤 종목 선택 + 랜덤 뉴스 이벤트 조합으로 같은 전략도 매번 다른 결과를 냅니다.

## 5. 차별화 포인트

| 기존 주식 게임의 문제 | 떡상러쉬의 해결 |
|----------------------|----------------|
| 복잡한 회원가입 필수 | 닉네임만 입력, 즉시 플레이 |
| 30분~1시간 플레이타임 | 50라운드, 15~20분 완결 구조 |
| 단순 주가 예측 반복 | 정보 구매 여부가 전략의 핵심 |
| 어렵고 딱딱한 UI | 한국 주식 밈 감성으로 친근하게 |
| 실시간 데이터 의존 | 완전 독립형 — 인터넷 없이도 동작 |

**핵심 차별화**: *"정보를 사는 것도 투자다"* — 정보 비대칭이라는 실제 주식 시장의 본질을 게임 메커니즘으로 구현한 것이 가장 큰 독창성입니다.

## 6. 화면 구성

| # | 화면 | 역할 |
|---|------|------|
| 0 | 시작 화면 | 닉네임 입력, 새 게임 / 이어하기 선택 |
| 1 | 메인 화면 | 잔고·보유종목 등락률·현재 라운드·등급 목표 표시, 장소 이동 버튼 |
| 2 | 거래소 (마켓) | 공개 10종목 분석·매수·매도 |
| 3 | 정보상 모달 | 국제뉴스·기업뉴스·추천종목 구매 |
| 4 | 기술상 모달 | 비공개 10종목 중 일부 유료 공개 + 투자 |
| 5 | 라운드 결과 모달 | 이번 라운드 수익/손실 요약, 다음 라운드 진행 |
| 6 | 결과 화면 | 최종 등급 + 랭킹 등록 (Supabase) |

### 디자인 방향
- 다크 테마 (증권사 HTS 느낌)
- 상승: 빨강 / 하락: 파랑 (한국 주식 관행)
- 모든 애니메이션 150ms 이하 — 빠른 게임 템포 유지
- 모바일(375px) ~ PC(1440px) 반응형

## 7. 기술 스택

| 역할 | 기술 |
|------|------|
| 프론트엔드 | React 18 + Vite |
| 스타일링 | Tailwind CSS |
| 상태 관리 | Zustand (localStorage persist) |
| 랭킹 백엔드 | Supabase (rankings 테이블 단독 사용) |
| 배포 | Vercel (GitHub 자동 배포) |
| AI 페어 프로그래밍 | Claude Code (Anthropic) — 바이브 코딩 (기획~배포 전 과정) |

> 게임 데이터(종목, 뉴스 이벤트)는 JSON 하드코딩 — 외부 API 의존 없음
