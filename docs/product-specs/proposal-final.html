한 줄 요약: “정보를 사는 것도 투자다” — 한국 실제 주봉 데이터를 기반으로, 정보 비대칭을 전략 자원으로 활용하는 50라운드 주식 시뮬레이션 미니게임

1. 게임 개요

떡상러쉬는 한국 주식 시장의 대세 상승장(2025년 5월 ~ 2026년 5월)을 배경으로, 50라운드 동안 정보의 비대칭을 활용해 자산을 불리는 웹 기반 주식 시뮬레이션 미니게임입니다.

플레이어는 1천만 원으로 시장에 진입합니다. 종목과 차트는 보이지만 — 진짜 중요한 정보는 숨겨져 있습니다. 정보상(情報商)에서 매 라운드 기업 뉴스를 무료로 확인하고, 다음 주 최고 상승 종목 힌트를 유료로 구매할 수 있습니다. 기술상(技術商)에게 돈을 내면 차트 지표와 비공개 종목 접근권을 살 수 있습니다.

항목내용
장르전략 시뮬레이션 / 경제 미니게임
플레이타임핵심 재미 10분 내 체험 가능, 전체 완주 15~20분
플랫폼브라우저 (PC + 모바일)

회원가입불필요 — 닉네임만 입력

2. 핵심 차별화

정보 비대칭 메커니즘

일반 주식 게임과 달리, 떡상러쉬는 정보 구매를 핵심 전략 자원으로 설계했습니다.

정보 비대칭 구조
─────────────────────────────────────────────────
모든 플레이어가 볼 수 있는 것
  ✓ 공개 10개 종목의 현재 주가 + 캔들스틱 차트
  ✓ KOSPI 지수 50주 흐름 차트
  ✓ 글로벌 거시경제 뉴스 1건 (매 라운드 자동 공개)
  ✓ 섹터별 기업 뉴스 3~5건 (정보상 방문 시 무료 확인)

돈을 내야만 알 수 있는 것
  💰 정보상 → 다음 주 최고 상승 종목 힌트 (총자산의 5%)
  💰 기술상 → 차트 기술 지표 4종 (MA·볼린저·MACD·OBV, 영구 적용)
  💰 기술상 → 비공개 10개 종목 거래 접근권 (패키지 구매)
─────────────────────────────────────────────────

이 구조는 실제 주식 시장의 본질(기관·개인 간 정보 격차)을 게임 메커니즘으로 번역한 것입니다.

실제 KOSPI 주봉 데이터 기반

가상 데이터가 아닌 2025년 5월 29일 ~ 2026년 5월 7일 실제 KOSPI 주봉 데이터를 사용합니다.

  • 이 기간 KOSPI는 2,697 → 7,498 (+177.9%) 대세 상승
  • 실제 섹터별 뉴스 207개와 날짜 매칭 — 실제 시장 흐름과 뉴스가 연동

기회비용 평가 시스템 (“벼락거지” 개념)

절대 수익률이 아닌 KOSPI 대비 초과수익률로 등급을 산정합니다.

“원금을 지켰더라도, +177.9% 상승장에서 현금만 들고 있었다면 당신은 벼락거지입니다.”

등급 체계 (6단계)

초과수익률(%p) = 내 최종 수익률(%) − KOSPI 수익률(+177.9%)
등급기준코멘트
👑 전설의 동학개미+100%p 이상“전설이 되셨습니다. 다음 생에도 주식 하세요.”
💰 슈퍼개미+30%p 이상“뛰어난 안목으로 시장을 크게 앞질렀습니다.”
🧠 스마트개미0%p 이상“코스피를 이겼습니다! 상승장에서 살아남았습니다.”
🐜 개미-60%p 이상“절반 이상의 구간은 놓쳤습니다.”
🐂 흑우-120%p 이상“투자는 했지만 시장이 너무 빨랐어요.”
💸 벼락거지-120%p 미만“기록적인 상승장에서 기회비용을 완전히 잃었습니다.”

4. 플레이 방식

전체 게임 루프

1. URL 접속 → 닉네임 입력 → IntroScene
      ↓
2. [메인 화면] 자산 현황 · 보유 종목 · KOSPI 차트 확인
      ↓
   +--------------------------------------------------+
   |  [거래소] 종목 캔들차트 분석 + 매수/매도         |
   |  [정보상] 뉴스 확인 · 내부 정보 구매             |
   |  [기술상] 차트 지표 구매 · 비공개 종목 패키지    |
   +--------------------------------------------------+
      ↓
3. [다음 주 ▶] 버튼 → 주가 변동 반영
      ↓
4. 2~3을 50회 반복  →  5. [결과 화면] 등급 확인 → 랭킹 등록

단계플레이어 행동화면
1잔고(8,432,000원)와 보유 종목 등락률 확인메인 화면

3거래소 방문 — 뉴스 힌트 기반 반도체 종목 매수거래소
4[다음 주 ▶] 클릭 → 반도체 종목 +4.3% 상승메인 화면 갱신

구간별 경험 설계

라운드 구간경험 내용
1~5라운드무료 뉴스 참고 — 불확실한 시장 → 정보 구매 고민 시작
5~10라운드첫 내부 정보 구매 → 힌트가 맞았을 때의 쾌감
10라운드~기술상 즉시 개방 → 비공개 종목 진입 기회
15~50라운드전략 분기 선명: 정보 투자형 vs. 종목 집중형

5. 3 NPC 상인 시스템

거래소

공개 10개 종목을 거래합니다.

  • 종목 클릭 → 캔들스틱 차트 확인 → 매수/매도 수량 입력
  • 구매한 차트 지표가 차트에 영구 반영
  • KODEX 200(지수 추종) / 인버스 ETF(역방향 전략) 항상 공개

정보상

3개 오브젝트(지구본 · 서류가방 · 태블릿)를 클릭해 정보를 획득합니다.

기업 뉴스섹터별 3~5건 (호재/악재 힌트)무료
내부 정보다음 주 최고 상승 종목 공개총자산의 5% (라운드당 1회)

뉴스 170개 풀을 실제 날짜 기반으로 매칭합니다.

6. 주요 재미 요소

정보 비대칭의 긴장감

매 라운드 “추천 종목 정보를 살 것인가, 그 돈으로 직접 투자할 것인가”라는 판단이 긴장감을 만듭니다. 정보가 맞으면 쾌감, 틀리면 분노 → 재도전 욕구를 자극합니다.

한국 주식 밈 감성

종목명·뉴스 헤드라인·등급 코멘트에 한국 주식 커뮤니티의 공감대를 녹였습니다.

  • 뉴스 예시: “동학개미 집결, 코스피 지지선 사수” / “외국인 매도 폭탄… 개미들 패닉셀”
  • 등급 코멘트: “전설이 되셨습니다” / “기록적인 상승장에서 벼락거지가 되셨네요”

랭킹 경쟁으로 반복 플레이 유도

50라운드 완료 후 전체 순위에 닉네임과 수익률을 등록합니다.

매 게임 다른 경험

공개 종목 8개가 랜덤 조합으로 구성 — 같은 전략이 매번 통하지 않습니다.
