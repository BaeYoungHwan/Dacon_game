## 1. 게임 개요

**떡상러쉬**는 한국 주식 시장의 **대세 상승장(2025년 5월 ~ 2026년 5월)** 을 배경으로, 50라운드 동안 **정보의 비대칭**을 활용해 자산을 불리는 웹 기반 주식 시뮬레이션 미니게임입니다.

플레이어는 1천만 원으로 시장에 진입합니다. 종목과 차트는 보이지만 — 진짜 중요한 정보는 숨겨져 있습니다. **정보상(情報商)** 에서 매 라운드 기업 뉴스를 무료로 확인하고, 다음 주 최고 상승 종목 힌트를 유료로 구매할 수 있습니다. **기술상(技術商)** 에게 돈을 내면 차트 지표와 비공개 종목 접근권을 살 수 있습니다. 어디에 투자할지 — 매 라운드 플레이어의 판단이 결과를 바꿉니다.

| 항목 | 내용 |
|------|------|
| 장르 | 전략 시뮬레이션 / 경제 미니게임 |
| 플레이타임 | 핵심 재미 10분 내 체험 가능, 전체 완주 15~20분 |
| 플랫폼 | 브라우저 (PC + 모바일) |
| 별도 설치 | 없음 — URL 접속 즉시 플레이 |
| 회원가입 | 불필요 — 닉네임만 입력 |

## 2. 핵심 차별화

### 정보 비대칭 메커니즘

일반 주식 게임과 달리, **떡상러쉬는 정보 구매를 핵심 전략 자원으로 설계**했습니다.

```
정보 비대칭 구조
─────────────────────────────────────────────────
모든 플레이어가 볼 수 있는 것
  ✓ 공개 10개 종목의 현재 주가 + 캔들스틱 차트
  ✓ KOSPI 지수 50주 흐름 차트
  ✓ 글로벌 거시경제 뉴스 1건 (매 라운드 자동 공개)
  ✓ 섹터별 기업 뉴스 3~5건 (정보상 방문 시 무료 확인)

돈을 내야만 알 수 있는 것
  💰 정보상 → 다음 주 최고 상승 종목 힌트 (총자산의 5%)
  💰 기술상 → 차트 기술 지표 4종 (MA·볼린저·MACD·OBV, 영구 적용)
  💰 기술상 → 비공개 10개 종목 거래 접근권 (패키지 구매)
─────────────────────────────────────────────────
```

이 구조는 실제 주식 시장의 본질(기관·개인 간 정보 격차)을 게임 메커니즘으로 번역한 것입니다.
"추천 종목 정보를 살 것인가, 그 돈으로 직접 투자할 것인가" — 매 라운드의 선택이 플레이어를 몰입하게 합니다.

### 실제 KOSPI 주봉 데이터 기반

가상 데이터가 아닌 **2025년 5월 29일 ~ 2026년 5월 7일 실제 KOSPI 주봉 데이터**를 사용합니다.

- 이 기간 KOSPI는 **2,697 → 7,498 (+177.9%)** 대세 상승
- 실제 섹터별 뉴스 170개와 날짜 매칭 — 실제 시장 흐름과 뉴스가 연동

### 기회비용 평가 시스템 ("벼락거지" 개념)

절대 수익률이 아닌 **KOSPI 대비 초과수익률**로 등급을 산정합니다.

> "원금을 지켰더라도, +177.9% 상승장에서 현금만 들고 있었다면 당신은 **벼락거지**입니다."

단순한 수익 여부가 아닌, 시장 대비 내 선택이 얼마나 좋았는지를 체감하게 합니다.

## 3. 핵심 규칙

| 항목 | 내용 |
|------|------|
| 초기 자본 | 10,000,000원 (1천만 원) |
| 총 라운드 | 50라운드 (각 라운드 = 실제 1주(週) 거래 단위) |
| 데이터 기반 | KOSPI 실제 주봉 2025-05-29 ~ 2026-05-07 (50주) |
| 종목 수 | 총 22개 (일반 20종목 + ETF 2개, 실제 KOSPI 종목 기반) |
| 공개 종목 | 10개 — KODEX 200 + 인버스 ETF 고정 + 랜덤 8개 |
| 비공개 종목 | 12개 — 기술상 패키지 구매 시 거래 가능 |
| 승리 기준 | KOSPI 대비 초과수익률(%p)로 6단계 등급 결정 |

### 등급 체계 (6단계)

```
초과수익률(%p) = 내 최종 수익률(%) − KOSPI 수익률(+177.9%)
```

| 등급 | 기준 | 코멘트 |
|------|------|--------|
| 👑 전설의 동학개미 | +100%p 이상 | "전설이 되셨습니다. 다음 생에도 주식 하세요." |
| 💰 슈퍼개미 | +30%p 이상 | "뛰어난 안목으로 시장을 크게 앞질렀습니다." |
| 🧠 스마트개미 | 0%p 이상 | "코스피를 이겼습니다! 상승장에서 살아남았습니다." |
| 🐜 개미 | -60%p 이상 | "절반 이상의 구간은 놓쳤습니다." |
| 🐂 흑우 | -120%p 이상 | "투자는 했지만 시장이 너무 빨랐어요." |
| 💸 벼락거지 | -120%p 미만 | "기록적인 상승장에서 기회비용을 완전히 잃었습니다." |

> 달성 가능성: 삼성전자 올인 시 +384% → 초과 +206%p로 전설 등급 달성 가능.
> 단, 게임마다 랜덤으로 비공개 종목이 될 수 있어 희귀도 설계 의도 유지.

## 4. 플레이 방식

### 전체 게임 루프

```
1. URL 접속 → 닉네임 입력 → 대세 상승장 배경 설명 (IntroScene)
      ↓
2. [메인 화면] 자산 현황 · 보유 종목 · KOSPI 차트 확인
      ↓
   +--------------------------------------------------+
   |  [거래소] 종목 캔들차트 분석 + 매수/매도         |
   |  [정보상] 뉴스 확인 · 내부 정보 구매             |  ← 매 라운드 자유 선택
   |  [기술상] 차트 지표 구매 · 비공개 종목 패키지    |
   +--------------------------------------------------+
      ↓
3. [다음 주 ▶] 버튼 → 라운드 전환 애니메이션 → 주가 변동 반영
      ↓
4. 2~3을 50회 반복
      ↓
5. [결과 화면] 최종 등급 확인 → 닉네임 랭킹 등록
```

### 한 라운드의 흐름 (12라운드 예시)

| 단계 | 플레이어 행동 | 화면 |
|------|-------------|------|
| 1 | 잔고(8,432,000원)와 보유 종목 등락률 확인 | 메인 화면 |
| 2 | 정보상 방문 — 기업 뉴스 확인 후 내부 정보 구매 고민 | 정보상 |
| 3 | 거래소 방문 — 뉴스 힌트 기반 반도체 종목 매수 | 거래소 |
| 4 | [다음 주 ▶] 클릭 → 반도체 종목 +4.3% 상승 | 메인 화면 갱신 |
| 5 | 수익 확인 후 다음 라운드 전략 재수립 | 메인 화면 |

### 구간별 경험 설계

| 라운드 구간 | 경험 내용 |
|-----------|-----------|
| 1~5라운드 | 무료 뉴스 참고 — 불확실한 시장 → 정보 구매 고민 시작 |
| 5~10라운드 | 첫 내부 정보 구매 → 힌트가 맞았을 때의 쾌감 |
| 10라운드~ | 기술상 즉시 개방 → 비공개 종목 진입 기회 |
| 15~50라운드 | 전략 분기 선명: 정보 투자형 vs. 종목 집중형 |

## 5. 3 NPC 상인 시스템

### 거래소

공개 10개 종목을 거래합니다.

- 종목 클릭 → 캔들스틱 차트 확인 → 매수/매도 수량 입력
- 구매한 차트 지표가 차트에 영구 반영
- KODEX 200(지수 추종) / 인버스 ETF(역방향 전략) 항상 공개

### 정보상

3개 오브젝트(지구본 · 서류가방 · 태블릿)를 클릭해 정보를 획득합니다.

| 항목 | 내용 | 비용 |
|------|------|------|
| 글로벌 뉴스 | 거시경제 뉴스 1건 | 무료 |
| 기업 뉴스 | 섹터별 3~5건 (호재/악재 힌트) | 무료 |
| 내부 정보 | 다음 주 최고 상승 종목 공개 | **총자산의 5%** (라운드당 1회) |

뉴스 170개 풀을 실제 날짜 기반으로 매칭합니다.

### 기술상

10라운드 이후 개방됩니다.

**차트 지표 구매 (영구 적용):**

| 지표 | 가격 | 해금 조건 |
|------|------|----------|
| MA5 + MA20 | 200,000원 | 10라운드 이후 |
| OBV | 400,000원 | 15라운드 이후 |
| 볼린저 밴드 | 600,000원 | 20라운드 이후 |
| MACD | 800,000원 | 30라운드 이후 |

**비공개 종목 패키지:** 비공개 12종목 중 랜덤 3~5개 번들 제공 (종목당 100만~200만 원 수준)

## 6. 주요 재미 요소

### 정보 비대칭의 긴장감

매 라운드 "추천 종목 정보를 살 것인가, 그 돈으로 직접 투자할 것인가"라는 판단이 긴장감을 만듭니다. 정보가 맞으면 쾌감, 틀리면 분노 → 재도전 욕구를 자극합니다.

### 한국 주식 밈 감성

종목명·뉴스 헤드라인·등급 코멘트에 한국 주식 커뮤니티의 공감대를 녹였습니다.

- 뉴스 예시: *"동학개미 집결, 코스피 지지선 사수"* / *"외국인 매도 폭탄… 개미들 패닉셀"*
- 등급 코멘트: *"전설이 되셨습니다"* / *"기록적인 상승장에서 벼락거지가 되셨네요"*

### 랭킹 경쟁으로 반복 플레이 유도

50라운드 완료 후 전체 순위에 닉네임과 수익률을 등록합니다. "1등과의 차이가 얼마지?"가 재도전을 유발합니다.

### 매 게임 다른 경험

공개 종목 8개가 랜덤 조합으로 구성 — 같은 전략이 매번 통하지 않습니다.

## 7. 차별화 포인트

| 기존 주식 게임의 문제 | 떡상러쉬의 해결 |
|----------------------|----------------|

| 수익률만 보여주는 결과 | KOSPI 대비 초과수익률 + "벼락거지" 기회비용 체감 |

## 8. 디자인 컨셉

**사이버펑크 HUD 테마** — 한국 HTS(홈 트레이딩 시스템)의 디지털 보드 감성을 사이버펑크 미학으로 재해석

- **배경**: slate-900/950 다크 톤
- **강조**: cyan-400/300 시안 글로우 효과
- **상승/하락**: 빨강(↑) / 파랑(↓) — 한국 주식 관행 준수
- **애니메이션**: 100~200ms 이하, 라운드 전환 1초 페이드
- **반응형**: 모바일(375px) ~ PC(1920px) 전 해상도 지원

## 11. 화면 구성

전체 6개 화면으로 구성됩니다. 모든 화면은 사이버펑크 HTS 테마(slate-950 다크 배경 + cyan 글로우)를 공유합니다.

### 화면 1 — 시작 화면 (`StartPage`)

```
┌─────────────────────────────────────────┐
│         [한국거래소 배경 이미지]          │
│                                         │
│           떡상러쉬                      │
│    정보를 사는 것도 투자다               │
│                                         │
│         [ 닉네임 입력창 ]               │
│      [ 새 게임 ] [ 이어하기 ]           │
└─────────────────────────────────────────┘
```

- 닉네임만 입력하면 즉시 게임 시작 (회원가입 불필요)
- 이전 진행 상태가 있으면 "이어하기" 버튼 활성화 (localStorage 복원)

---

### 화면 2 — 메인 화면 (`GamePage`)

```
┌──────────────┬──────────────────────────────────────┐
│ [자산 카드]  │  [KOSPI compact ticker]  [⚙ 설정]   │
│              ├──────────────────────────────────────┤
│ ROUND 12/50  │                                      │
│ 총자산       │   [거래소NPC]  [정보상NPC]  [기술상NPC]│
│ 현금 / 평가액│        클릭 → 해당 화면 이동         │
│ 보유 종목 목록│                                      │
│              ├──────────────────────────────────────┤
│              │  ▶ TIPS: 오늘의 투자 팁 전광판        │
│              │                      [다음 주 ▶]     │
```
