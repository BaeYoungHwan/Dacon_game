## 1. 개요

한국 주식 시장을 배경으로, 15~20분 내외로 플레이하며 자산을 불리는 웹 기반 시뮬레이션 미니게임

## 2. 문제 정의

짧은 여가 시간에 가볍게 즐길 수 있는 주식 시뮬레이션이 없다. 기존 주식 게임은 복잡한 회원가입, 긴 플레이타임, 과한 UI로 진입 장벽이 높다. 밈 감성으로 포장된 빠르고 직관적인 한국 주식 테마 게임이 필요하다.

## 3. 타겟 유저

| 페르소나 | 설명 | 주요 시나리오 |
|----------|------|---------------|
| 미니게임 유저 | 짧고 강렬한 재미를 원하는 웹 게임 플레이어 | 링크 공유로 바로 진입, 닉네임 입력 후 즉시 플레이 |
| 밈/투자 관심 10~30대 | 주식·투자에 관심 있거나 한국 주식 밈을 즐기는 사용자 | 실제 종목명·뉴스 이벤트에서 공감 유도, 랭킹으로 경쟁 |

## 4. 성공 지표 (KPI)

- 핵심 사이클(매수 → 턴 진행 → 매도) 완벽 구현
- 평균 플레이 타임 15~20분 달성
- 해커톤 마감일(2026-05-18) 전 MVP 배포 완료

## 5. 기술 스택

React 18 + Vite + Tailwind CSS + Zustand (상태 관리) + Supabase (랭킹 보드)

## 6. 배포 환경

Vercel (GitHub master 브랜치 자동 배포)

## 7. MVP 핵심 기능

> 이번 버전에서 반드시 구현할 기능

- [ ] 턴(일자) 진행 시스템
- [ ] 종목별 랜덤 가격 변동 및 뉴스 이벤트 (호재/악재 텍스트 출력)
- [ ] 주식 매수/매도 및 인벤토리(보유 주식) 관리
- [ ] 최종 자산 평가 및 결과 화면
- [ ] 닉네임 입력 및 최종 자산 랭킹 보드 등록/조회 (Supabase)

## 8. MVP 제외 사항 ⚠️

> Claude는 아래 항목을 임의로 구현하지 않습니다.

- **실시간** 주식 데이터 API 연동 (KRX, 네이버 금융 실시간 호출)
  - ※ 단, 실제 시장 종목명·가격을 **참조**하여 JSON으로 하드코딩하는 것은 허용
  - 예: 네이버 금융에서 오늘 종가 확인 후 `stocks.json`에 직접 입력
- 백엔드 서버 및 별도 DB 구축 (랭킹 외 모든 데이터는 로컬 스토리지)
- 소셜 로그인 및 회원가입 시스템

## 9. 데이터 전략 (v1.1 추가)

### 종목 데이터 (`stocks.json`)
- 실제 한국 주식 종목 10개 내외 사용 (삼성전자, SK하이닉스, 카카오 등)
- 초기 가격: 네이버 금융 기준 당일 종가 참조 후 하드코딩
- 섹터 분류: 반도체 / IT / 자동차 / 바이오 / 금융 등

```json
[
  { "id": "005930", "name": "삼성전자", "price": 74800, "sector": "반도체" },
  { "id": "000660", "name": "SK하이닉스", "price": 189500, "sector": "반도체" },
  { "id": "035720", "name": "카카오", "price": 41050, "sector": "IT" }
]
```

### 뉴스 이벤트 데이터 (`news-events.json`)
- 실제 한국 주식 시장에서 발생한 이벤트 패턴 참조 (역사적 사건 기반)
- 각 이벤트: 헤드라인 텍스트 + 대상 섹터/종목 + 가격 영향 계수
- 호재(+) / 악재(-) 균형 있게 구성

```json
[
  { "id": "e1", "headline": "美 반도체 수출 규제 강화 발표", "sector": "반도체", "effect": -0.08 },
  { "id": "e2", "headline": "AI 붐으로 HBM 수요 폭발, 공급 부족 우려", "sector": "반도체", "effect": 0.12 },
  { "id": "e3", "headline": "카카오 계열사 SM엔터 인수 소식", "sector": "IT", "effect": 0.07 }
]
```
