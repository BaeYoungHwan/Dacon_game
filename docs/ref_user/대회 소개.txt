

[대회소개]
게임은 짧은 시간 안에 이용자의 흥미를 끌고, 직관적인 규칙과 반복 플레이를 통해 재미를 전달해야 합니다.

특히 웹 기반 미니게임은 설치 없이 바로 실행할 수 있어 접근성이 높지만 제한된 플레이타임 안에서 완성도와 몰입감을 모두 갖춘 게임을 설계하는 것은 쉽지 않습니다.

또한 짧은 형식 안에서도 차별화된 아이디어, 적절한 난이도, 자연스러운 게임 흐름을 함께 구현해야 하므로 단순한 기능 구현을 넘어 플레이 경험 전반에 대한 설계 역량이 요구됩니다.

이번 대회에서는 바이브 코딩을 활용하여 웹에서 바로 실행 가능한 게임을 기획하고 구현하는 온라인 게임 개발 챌린지를 진행합니다.

참가자는 특정 장르에 제한 없이 자유롭게 게임을 설계하되, 실제로 플레이 가능한 형태의 웹 서비스로 구현해야 합니다.

개발/배포 규칙
배포 URL은 외부에서 접속 가능해야 하며 심사 기간 동안 접근 가능해야 합니다.

기술 제한 없이 바이브 코딩 툴을 활용하여 개발해야 합니다.

외부 API 사용 시 심사자가 별도 키 없이 확인 가능해야 합니다.

공정성/저작권
제출물(코드/이미지/폰트/아이콘 등)은 저작권·라이선스를 준수해야 합니다.

타인의 결과물을 무단 복제/도용하거나 라이선스를 위반한 경우 실격 또는 감점될 수 있습니다.

팀 내 역할/분업은 자유이며 생성형 AI 도구 사용은 허용합니다.

심사 관련 유의사항
심사는 기본적으로 배포 URL을 기준으로 진행합니다.

확인이 어려운 기능은 심사에서 제외될 수 있습니다.

운영진의 추가 안내가 있을 경우 공지 내용이 우선 적용됩니다.
