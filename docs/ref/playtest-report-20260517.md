## 발견된 버그 ⚠️

### [BUG-01] ＋ 버튼 빠른 연속 클릭 미반영 — 낮음

- **현상**: 매수 모달에서 ＋ 버튼을 빠르게 5번 클릭 시 1~2회만 반영됨
- **재현 경로**: 거래소 → 주식 구매 → 종목 행의 ＋ 버튼 빠른 연속 클릭
- **원인 추정**: React state 업데이트 batching으로 중간 클릭 이벤트 소실
- **영향**: 낮음 — 천천히 클릭하거나 MAX 버튼으로 완전히 우회 가능
- **권장 수정**: `onClick` → `onPointerDown` 변경 또는 수량 입력 필드 직접 편집 허용

---

### [BUG-02] 보유 종목 손익률 표시 이상 — 높음

- **현상**: 메인화면 HOLDINGS에서 삼성전자 ▼ -75.01% 표시 (49턴 시점)
- **실제 상황**: 매수가 56,100원, 49턴 현재가 56,180원으로 실제로는 소폭 상승 중
- **원인 추정**: `gameStore.js` 손익률 계산 시 매수가(purchasePrice)와 초기 기준가(basePrice) 혼용 가능성
- **영향**: 높음 — 플레이어가 잘못된 손익 정보로 의사결정 오류 유발, 완성도 점수에 직결
- **권장 수정**: `gameStore.js`에서 HOLDINGS 손익률 계산 로직 검토 및 단위 테스트 추가

## 결론

핵심 게임 플로우는 **크래시 없이 50턴 완주 성공**. 안정성은 양호하나 아래 2가지를 제출 전 반드시 수정 권장.

| 우선순위 | 항목 |
|---------|------|
| **즉시 수정** | BUG-02 손익률 표시 오류 (`gameStore.js` 확인) |
| **선택 수정** | BUG-01 ＋ 버튼 batching (MAX 버튼 우회 가능) |
| **수동 필수** | 매도 기능 / 랭킹 등록 직접 플레이테스트 |
