### 특수 종목

| 구분 | 종목 | 설명 |
|------|------|------|
| 특수 | 인버스 x2 | 매 게임 고정 포함 — 하락장 헤지 수단 |
| 이벤트 | 케이뱅크 IPO | 지정 라운드 이벤트로 등장 (신규 IPO 콘셉트) |

### 게임 내 종목 선택 방식
- 20섹터 중 **랜덤 10개 섹터** 선택 → 거래소 공개
- 나머지 10개 섹터 종목은 기술상에서 유료 공개
- 인버스 x2는 매 게임 **고정 포함**
- 케이뱅크 IPO는 지정된 라운드에 **이벤트 형태**로 등장

## 3. JSON 데이터 포맷

### 파일 위치
```
src/data/stockData.json
```

### 구조
```json
{
  "meta": {
    "rounds": 50,
    "dates": ["2025-05-29", "2025-06-05", "...", "2026-05-07"]
  },
  "kospi": [0.8, -1.2, 2.1],
  "stocks": [
    {
      "id": "stock_01",
      "realTicker": "005930",
      "mimeName": "반도체황제",
      "sector": "반도체",
      "basePrice": 10000,
      "prices": [
        { "open": 57500, "high": 60200, "low": 57000, "close": 58000, "volume": 12500000 }
      ],
      "news": [
        { "round": 3, "title": "HBM 수출 호조, 분기 최대 실적 예고", "type": "호재" }
      ]
    }
  ],
  "globalNews": [
    { "round": 1, "title": "미 연준 금리 동결 결정" }
  ]
}
```

### 필드 설명
| 필드 | 타입 | 설명 |
|------|------|------|
| `meta.dates` | string[] | 50개 주봉 기준일 목록 |
| `kospi` | number[] | 라운드별 코스피 주간 등락률(%) — 50개 |
| `kospi[]` | object[] | 라운드별 코스피 OHLCV — 50개 |
| `stocks[].prices[]` | object[] | 라운드별 종목 OHLCV — 50개 |
| `prices[].open` | number | 시가 |
| `prices[].high` | number | 고가 |
| `prices[].low` | number | 저가 |
| `prices[].close` | number | 종가 |
| `prices[].volume` | number | 거래량 (OBV 계산에 필요) |
| `stocks[].news[]` | object[] | 해당 종목 뉴스 (있는 라운드만) |
| `news[].round` | number | 해당 라운드 번호 |
| `news[].title` | string | 뉴스 헤드라인 |
| `news[].type` | string | `"호재"` / `"악재"` |
| `globalNews[]` | object[] | 주별 국제 뉴스 |

### 차트 지표 계산 방식
JSON에는 OHLCV + volume만 저장하고, 지표는 프론트에서 계산합니다.

| 지표 | 필요 데이터 | 비고 |
|------|-----------|------|
| 이동평균 (MA) | `close` | 5주·20주 |
| 볼린저 밴드 | `close` | 20주 기준 |
| MACD | `close` | 12·26·9 기본값 |
| OBV | `close` + `volume` | 누적 계산 |
| 거래량 차트 | `volume` | 막대 차트 |

> 정보상에서 1회 구매 시 해당 지표가 게임 끝까지 차트에 표시됩니다. 구매 상태는 Zustand store에 저장합니다.
